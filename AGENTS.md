# AGENTS.md

## Guidelines for This Repository

This file contains editorial and stylistic rules that all agents and contributors must follow when modifying this GitHub profile repository.

---

### Writing Style

- **No emoticons in text.** Do not use emoji or emoticons inline within English prose, descriptions, or any written content. Text must read with clarity and elegance on its own.
- **Tone.** Maintain a professional, refined, and composed tone throughout. Content should feel considered — never casual or decorative for its own sake.
- **Language.** Write in clear, grammatically correct English. Avoid informal abbreviations, slang, or filler words.

---

### README Standards

- All section headings must be centered using `<h3 align="center">`.
- Badge labels must be concise and properly capitalized.
- Avoid placeholder content. Every line must carry meaning.
- Quotes, if used, must be attributed accurately and chosen for their substance — not popularity.

---

### Asset Management

- All image and SVG assets must be placed under the `assets/` directory.
- Animated SVG badges are preferred over static images where appropriate, provided the animation remains subtle and purposeful.
