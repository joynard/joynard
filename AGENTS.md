# AGENTS.md

## Guidelines for This Repository

This file contains editorial and stylistic rules that all agents and contributors must follow when modifying this GitHub profile repository.

---

### Writing Style

- **No emoticons in text.** Do not use emoji or emoticons inline within English prose, descriptions, or any written content. Text must read with clarity and elegance on its own.
- **Tone.** Maintain a professional, refined, and composed tone throughout. Content should feel considered — never casual or decorative for its own sake.
- **Language.** Write in clear, grammatically correct English. Avoid informal abbreviations, slang, or filler words.

---

### README Standards

- All section headings must be centered using `<h3 align="center">`.
- Badge labels must be concise and properly capitalized.
- Avoid placeholder content. Every line must carry meaning.
- Quotes, if used, must be attributed accurately and chosen for their substance — not popularity.

---

### Asset Management

- All image and SVG assets must be placed under the `assets/` directory.
- Animated SVG badges are preferred over static images where appropriate, provided the animation remains subtle and purposeful.

---

### Visual System

- **Palette.** Ink `#0F0C09` and `#14100C`, leather `#704214`, terracotta `#A0522D`, brass `#C68642`, cream `#F5EDE0`. Structural elements stay inside this warm family; saturated brand colors belong only to third-party technology badges.
- **Typography.** A serif face carries the name, letter-spaced uppercase sans carries labels. No decorative or script faces.
- **Geometry.** Badges share height 28, corner radius 5, and a 1px brass hairline border. Icons are drawn as vector paths, never as font glyphs or emoji.
- **Rules.** Section separators are `assets/divider.svg`, reserved for the page opening and closing. Consecutive sections are separated by headings alone.
- **Motion.** At most one slow cycle per asset, 14 to 20 seconds, easing between adjacent tones of the same hue. Nothing flashes.
- **Metrics.** `assets/scorecard.svg` is generated by `scripts/scorecard.mjs` through `.github/workflows/scorecard.yml`. Never hand-edit it: change the renderer, then run the workflow. The README carries a `?v=` stamp that the workflow moves after each render, because GitHub's image proxy caches by URL.
